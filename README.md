# ThuyDung Fashion

A luxury fashion website inspired by Dior, built with Next.js and Tailwind CSS.

## Features

- Responsive design similar to Dior's website
- Product catalog
- Product detail pages
- Newsletter subscription
- Mobile-friendly navigation

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technology Stack

- Next.js
- React.js
- Tailwind CSS
- CSS Modules
